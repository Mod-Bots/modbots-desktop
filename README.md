# Mod Bots Desktop

Desktop application for Mod Bots.

This app is built with Tauri 2, Rust, React, TypeScript, and Vite.

## Prerequisites

- Node.js
- npm
- Rust
- Tauri prerequisites for your platform

## Install

```bash
npm install
```

## Development

Run the desktop app in development mode:

```bash
npm run tauri dev
```

If you only want the frontend dev server:

```bash
npm run dev
```

## Build

Build the frontend bundle:

```bash
npm run build
```

Build the desktop application:

```bash
npm run tauri build
```
